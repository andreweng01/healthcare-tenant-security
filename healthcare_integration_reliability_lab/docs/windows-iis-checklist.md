# Windows Server / IIS evidence checklist

This is a separate lab; this project alone does not establish Windows Server/IIS experience.

- Record Windows Server version and lab/VM setup.
- Install IIS and document selected role services.
- Create a test site and dedicated application pool.
- Configure binding/TLS and least-privilege file permissions.
- Deploy a small test application and verify its health endpoint.
- Trigger a controlled configuration failure; inspect IIS logs and Event Viewer.
- Recover the service and document root cause.
- Save redacted screenshots/logs and record exactly what you configured.
